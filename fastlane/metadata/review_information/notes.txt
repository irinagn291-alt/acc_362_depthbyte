The app opens on the Bridge without onboarding. Start the next dive, read the briefing, toggle between the lesson excerpt and complete program, then answer the two three-choice checks. Incorrect selections show a repair note and can be changed; complete both checks to finish the dive. Use the Depth Chart to browse unlocked dives or replay completed ones, and the Salvage Locker to view sector rewards and clean-dive progress. Progress and checkpoints are stored in UserDefaults. Content is bundled; there is no account, network service, third-party integration, data export or hardware permission request. The displayed C code is not executed. The interface is in English.
